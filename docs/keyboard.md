# Family BASIC keyboard

Select **Family BASIC** as the expansion device in **Controllers** settings,
then open **Media > Family BASIC Keyboard** with a game loaded. The window
shows all 72 keys in their keyboard layout. Pressed keys change color, including
keys held on a physical keyboard.

Hold the left mouse button on a key to press it. Release the button to release
the key. Right-click a key to latch it; right-click again to release it. Touch
input supports several held keys, so you can hold Shift and type another key.
A physical and an on-screen press of the same key stay held until both release.

The keyboard window sends physical keystrokes to the emulated keyboard while
it has focus. Text fields and menus take priority. Changing focus or closing
the window releases held host keys. Movie playback owns its recorded input;
the keyboard shows that state but does not accept edits during playback,
netplay, rewind, or speculative frames.
