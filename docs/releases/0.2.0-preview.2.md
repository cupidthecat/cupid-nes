# Cupid NES 0.2.0-preview.2

This preview reorganizes the GTK desktop around the task in each window.
Menus show shortcut hints, the main toolbar uses compact icons, and individual
tools have their own opening sizes and control groups.

Settings use tabs for longer categories. Overscan has a region-by-edge grid,
audio mixers pair volume with pan, and controller mappings pair keyboard and
gamepad bindings. General preferences and short settings pages keep their groups
together. Invalid pending values stay editable; Apply opens the tab containing
the error before returning focus to the field.

The debugger places CPU state and breakpoints beside disassembly. Memory tools
separate search criteria, results, selection edits, and file operations. The
header editor has ROM, RAM, and console tabs, with named format and region
choices and battery/trainer checkboxes. PPU windows group selection controls and
details. The assembler puts its preview and apply actions below the editors.

The README and desktop guide include new screenshots from the native regression
application. Its generated cartridge and movie make the captures reproducible.
The GTK checks now cover the registered tools and every settings tab, along with
settings transactions, debugger register edits, assembly, and TAS interactions.

## Windows package

Download `cupid-windows-x64.zip`, extract it into a new folder, and run
`cupid-nes.cmd`. The ZIP includes GTK, runtime libraries, and component licenses.
The accompanying SHA-256 file verifies the download. Installation is manual.

This is a preview release from the desktop PR branch. Physical controllers,
display-DPI changes, and game-specific behavior still need testing on their
respective hardware and software setups.
