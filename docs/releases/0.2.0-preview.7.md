# Cupid NES 0.2.0-preview.7

This preview fixes configurable keyboard shortcuts in the GTK desktop. The game
view now routes keyboard events through the active input profile, including
rewind, fast-forward, pause, frame advance, state save/load, reset, and mute.
Settings, fullscreen, and the palette editor shortcuts are also connected.

Hold **Ctrl+Backspace** to rewind with the default profile. Rewind needs retained
history and a nonzero rewind duration. Releasing the key stops rewind even if
Ctrl was released first. Moving focus to another control releases held input;
editors and menus keep their own keyboard input. Custom bindings work after
applying settings.

This release retains the accelerated Windows game viewport, restored-window
alignment fix, frame timing statistics, and live Game Information updates from
preview 6. The changes remain in [PR #205](https://github.com/cupidthecat/cupid-nes/pull/205),
which is not merged.

## Windows x64

Extract `cupid-windows-x64.zip` into a new folder and run `cupid-nes.cmd`.
Keep the `bin`, `lib`, `share`, and `etc` directories together. GTK and its runtime
libraries are included.

## Linux x64

The archive targets Ubuntu 24.04 on x86-64 and uses system libraries:

```sh
sudo apt install libgtk-4-1 libsdl2-2.0-0 libcurl4t64
tar -xzf cupid-linux-x64.tar.gz
cd cupid-linux-x64
./cupid-nes
```

Both downloads have SHA-256 files and complete file manifests. ROMs and BIOS
images are not included.
