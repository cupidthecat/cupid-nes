# Cupid NES 0.2.0-preview.3

Fixes GTK playback slowing down when the main window is enlarged or a tool
window is open. The GTK desktop no longer renders or waits for VSync on its
hidden SDL host window. Emulation continues to use the NES frame deadline,
including the selected region and speed.

Windows measurements with an NTSC diagnostic cartridge improved from roughly
45 FPS with the timing tool open to 60.0–60.1 FPS after the window settled.
Actual performance also depends on the game, video filters, tools, and host.

## Windows x64

Extract `cupid-windows-x64.zip` into a new folder and run `cupid-nes.cmd`.
Keep its `bin`, `lib`, `share`, and `etc` directories together. GTK and the
other runtime libraries are included.

## Linux x64

The new `cupid-linux-x64.tar.gz` download targets Ubuntu 24.04 x86-64 and uses
system runtime libraries. Install them, extract the archive, and start Cupid:

```sh
sudo apt install libgtk-4-1 libsdl2-2.0-0 libcurl4t64
tar -xzf cupid-linux-x64.tar.gz
cd cupid-linux-x64
./cupid-nes
```

Both downloads include component licenses and a manifest. The accompanying
SHA-256 files verify the archives. This prerelease is built from the existing
desktop PR branch; installation is manual.
