# Cupid NES 0.2.0-preview.6

This preview improves frame delivery and fixes stale Game Information.

Windows now uses an accelerated SDL game viewport, preferring Direct3D 11.
GTK keeps its normal desktop compositor. Scaling the game on the GPU reduces
the cost of maximized and fullscreen output. The game viewport also fits the
GTK layout correctly in restored and smaller windows, including at 200% scaling.

Game Information refreshes after loading another game and while the window
stays open. It shows the game renderer separately from the desktop compositor.
Frame Timing Statistics reports emulation and display draw rates, with interval
jitter to help identify uneven motion. Frame waits use the high-resolution clock
and process pending desktop work between frames.

The release includes the desktop tools, movie and capture features, and emulator
improvements in [PR #205](https://github.com/cupidthecat/cupid-nes/pull/205).
It is published from that branch without merging the PR.

## Windows x64

Extract `cupid-windows-x64.zip` into a new folder and run `cupid-nes.cmd`.
Keep the `bin`, `lib`, `share`, and `etc` directories together. The archive
includes GTK and its runtime libraries.

Game Information should show an accelerated SDL video renderer during play.
The desktop compositor can still say `GskCairoRenderer`. Remove an old
`GSK_RENDERER=cairo` environment override to use the accelerated game viewport;
that override remains available for software fallback.

## Linux x64

The Linux archive targets Ubuntu 24.04 on x86-64 and uses system libraries.
Install the runtime dependencies, extract it, and launch Cupid:

```sh
sudo apt install libgtk-4-1 libsdl2-2.0-0 libcurl4t64
tar -xzf cupid-linux-x64.tar.gz
cd cupid-linux-x64
./cupid-nes
```

Both archives include component licenses and a file manifest. Verify each
download with its accompanying SHA-256 file. ROMs and BIOS images are not included.
