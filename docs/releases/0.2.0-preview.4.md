# Cupid NES 0.2.0-preview.4

This preview fixes slow game presentation in large Windows windows. On GTK
4.24 or newer, Cupid enables DirectComposition so GTK can use GPU rendering
when the main window is maximized or fullscreen. Game Information shows the
active video renderer. Unchanged window captions no longer trigger repeated
updates, and closing a maximized window preserves its saved window size.

The included SMB3 USA Rev 1 benchmark held 60.10 FPS at normal speed in
windowed, maximized, and fullscreen views, including with a PPU viewer open.
The measurements cover the game's opening sequence on one Windows machine.
Results vary with graphics hardware, drivers, game timing, and settings.

The release also includes the desktop and emulator improvements listed in
[PR #205](https://github.com/cupidthecat/cupid-nes/pull/205).

## Windows x64

Extract `cupid-windows-x64.zip` into a new folder and run `cupid-nes.cmd`.
Keep the `bin`, `lib`, `share`, and `etc` directories together. The archive
includes GTK and its runtime libraries.

## Linux x64

The Linux archive targets Ubuntu 24.04 on x86-64 and uses system libraries.
Install the runtime dependencies, extract it, and launch Cupid:

```sh
sudo apt install libgtk-4-1 libsdl2-2.0-0 libcurl4t64
tar -xzf cupid-linux-x64.tar.gz
cd cupid-linux-x64
./cupid-nes
```

Both archives include component licenses and a file manifest. Verify each
download with its accompanying SHA-256 file. ROMs and BIOS images are not
included.

## Validation

AccuracyCoin passed 144/144 with no skips or unfinished tests. The CPU trace,

passed on the source revision. Both platform archives were checked for
