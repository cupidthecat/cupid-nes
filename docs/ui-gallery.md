## Reproduce the captures

Build with `make GTK=1 gtk-smoke`. On Linux:

```sh
xvfb-run -a env GSK_RENDERER=cairo G_DEBUG=fatal-criticals SDL_AUDIODRIVER=dummy ./build/gtk-ui-smoke build/gtk-smoke
```

The output folder contains default, large, and small window captures, tool tabs,
and every settings tab. The GTK workflow uploads the complete capture folder as
an artifact. The GTK checks also cover input handling, settings transactions,
register commits, assembler editing, and TAS operations.
