# Support

For build or runtime problems, start with
[getting started](docs/getting-started.md) and
[troubleshooting](docs/troubleshooting.md). The
[documentation index](docs/README.md) links configuration, controls, supported
hardware, and save-file behavior.

Use [GitHub issues](https://github.com/cupidthecat/cupid-nes/issues) for a bug
report, a documentation question, or a feature proposal. Search existing issues
for the same symptom first and add a reproducer there when it matches.

Include the Cupid commit, operating system, exact build and launch commands,
and the relevant terminal output. For a game problem, include its title, region,
mapper/submapper when known, and image hash. Explain what you expected, what
happened, and the steps needed to reach it. A public diagnostic ROM or a small
reproducer helps when one is available.

For a save problem, identify the save type, destination, write-protection state,
and the operation that reports the failure, such as loading, tape stop, or exit.
Check the [saves guide](docs/saves.md) before moving files while the emulator has
modified media in memory.

The [contribution guide](CONTRIBUTING.md) explains how to submit a patch and
report its validation. Accuracy results should include the tested commit,
command, and any required ROM setup conditions.
